Security Insights

Random Method: Generates mathematically unlinked character strings using cryptographically secure values (`crypto.getRandomValues`). Offers high entropy but can be hard to memorize.

Passphrase Method: Combines multiple random words. Even though words are simple, combining 4-5 words creates an incredibly long password with extremely high entropy that is easy to recall. Highly recommended by cybersecurity authorities!

Readable Method: Alternates vowels and consonants, mimicking pronounceable syllables. Easier to remember than random strings, but yields lower entropy per character than pure randomness.
